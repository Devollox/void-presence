First‑time setup
Step 1 — Discord Client ID
  1. Open https://discord.com/developers/applications.
  2. Create or select an existing application.
  3. Add an app icon 1024×1024 (PNG / JPG / GIF / WEBP, up to 10 MB).
  4. Copy the Application ID from the overview page.
  5. Paste it into the client id field above.
Step 2 — Start your presence
  • Click Presence activity tumbler to enable RPC.
  • Set update(sec) to how often presence should refresh.
  • Pick an activity type: playing / watching / listening / competing.
  • Click RESTART PRESENCE to apply your settings.
Step 3 — Troubleshooting
  • If you see Connection closed, very long connecting, or frequent disconnects in the log console, but Discord itself works fine, try restarting Discord.

Custom status

Use this feature with caution. It relies on a user token and behaves like a third‑party client, which is against Discord's Terms of Service, so you use it at your own risk.

We do not accept any responsibility for possible consequences, including warnings or account restrictions, although we have not observed bans for this specific use case so far.

Never share your Discord token with anyone! Never show it to anyone, never send it to anyone, and never paste it anywhere except this field. Your token gives full access to your Discord account.

Step 1 — Enable status and set up cycles
  1. Toggle Custom status to turn the worker on.
  2. Set Discord token in the field below.
  3. Set update(sec) — how often the status should change (minimum 5 seconds).
  4. Add one or more status cycles with text and optional emoji.
Step 2 — Get Discord token
  • Open Discord in a desktop browser and log in to your account.
  • Open DevTools with F12 or Ctrl+Shift+I.
  • Switch to the Network tab and in the lower panel select the science request.
  • Inside the science request, find the authorization header and copy its full value.
  • Paste the copied user token into the DISCORD TOKEN field below.
  • Click RESTART STATUS to restart the worker with the new token and cycles.
Step 3 — Important notes
  • We do not store your Discord token on any server. It is used locally on your machine only.
  • For most setups we recommend an update interval between 60 and 90 seconds to keep your status responsive without spamming Discord.
  • If your main RPC presence already updates every 5 seconds, it is not recommended to set the status interval lower than 60 seconds.

Cloud profiles
Step 1 — Prepare your profile
  1. Set up your presence, details, images and buttons the way you like.
  2. Enter a short config name in the field above.
  3. Optionally add your author ID (from voidpresence.site/profile) to link the profile to your account.
  4. Click save config to store this setup locally.
Step 2 — Upload to cloud
  • Select the profile you want in saved configs.
  • Make sure author ID is set for this profile.
  • Click upload.
  • Confirm in the Upload config? dialog to overwrite the cloud copy.
