Custom status

Use this feature with caution. It relies on a user token and behaves like a third-party client, which is against Discord's Terms of Service, so you use it at your own risk.
1 Toggle Custom status to turn the worker on. Set Discord token in the field below.
2 Open DevTools with F12 or Ctrl+Shift+I. Switch to the Network tab, select the science request, find the authorization header and copy its value.
3 Paste the copied user token into the DISCORD TOKEN field, set update interval (60–90s recommended), add status cycles.
